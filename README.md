# DAVE

A deliberately stupid incremental game built in Godot 4.

## V0.1 loop

DAVE digs automatically → dirt accumulates → sell dirt for cash → buy more Daves and better shovels → the pit fills with increasingly too many Daves.

## Run

Open `project.godot` in Godot 4.x and press F6/F5.

## Current systems
- Automatic digging economy
- Sell dirt for cash
- Exponential Dave pricing
- Shovel upgrades
- Up to 80 visible Daves (economy can exceed this)
- Persistent save
- Capped offline progress
- Zero external art dependencies; placeholder Daves are drawn in-engine

Next target: animated digging, terrain layers/resources, milestone unlocks, specialized Daves, and first prestige loop.
